One haiku about debugging, three lines in the 5-7-5 syllable shape, for the
[Seventeen Syllables of Debugging](https://make.fun) competition on make.fun.
A red breakpoint blinks at 3am, the log line crawls past midnight — and the
last line turns the whole night around: the bug wore my face.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the haiku (80 characters, 3 lines, 5-7-5) to
`/output/entry.txt`, creating `/output` if needed. It validates the entry
before writing: exactly 3 lines, 17 syllables total, 1–200 characters.
